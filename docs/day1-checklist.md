# Day 1 checklist

## Accounts and safety
- [ ] GitHub repo created (public) and cloned locally
- [ ] AWS account: create a Budget with an alert at about $5
- [ ] AWS: use an IAM user/role with limited permissions (not the root user)

## Tools (run each and note the version)
- [ ] git --version
- [ ] python --version        (3.11 or newer)
- [ ] java -version           (17 or newer)
- [ ] mvn -v
- [ ] gauge --version         (then: gauge install java)
- [ ] docker --version
- [ ] aws --version
- [ ] A code editor with a Gauge/Java plugin (IntelliJ or VS Code)

## Repo
- [ ] Copy this starter kit into the repo, commit, push
- [ ] Open docs/scoring.md and read the formula
- [ ] Open each fixture in a browser; try tabbing through with the keyboard

## End of day
- [ ] Commit with a clear message; update README status
